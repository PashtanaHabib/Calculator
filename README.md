
# Calculator

A small practice project built with **HTML, CSS, and JavaScript**.

This project is created for practicing basic JavaScript concepts by building a simple and interactive calculator.

## Live Demo

[View Live Demo](https://pashtanahabib.github.io/Calculator/)

## Features

- Addition, subtraction, multiplication, and division
- Percentage calculation
- Clear all (AC)
- Delete last character (DEL)
- Decimal number support
- Interactive buttons with hover effects
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## JavaScript Concepts & Methods Used

### DOM Manipulation
- `getElementById()`
- `querySelectorAll()`

### Event Handling
- `addEventListener()`
- `dataset`

### Array Methods
- `forEach()`

### String Methods
- `slice()`
- `split()`
- `pop()`
- `includes()`
- `match()`

### Number Methods & Functions
- `Number()`
- `toFixed()`
- `toString()`
- `isFinite()`

### Other JavaScript Concepts
- Conditional Statements (`if...else`)
- Error Handling (`try...catch`)
- Regular Expressions (RegEx)
- `eval()`
- Callback Functions

## Project Purpose

This is a small educational project created to practice JavaScript fundamentals, DOM manipulation, event listeners, array methods, string methods, and basic mathematical operations.
